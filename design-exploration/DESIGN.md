# Ken Liu 個人品牌網站：四種風格探索

日期：2026-10-26。分支：`codex/personal-brand-design-exploration`。

## 交付目標

同一個完整個人品牌網站，在上方選單切換四種風格。每種風格有獨立的首屏骨架、字體語氣、色彩及全站材質；下方內容使用單一資料來源，搜尋、作品篩選、展開狀態不因切換風格而重設。

訪客先認識劉炳祥的「財務實務 × 資料分析 × AI 開發」，再看作品或聯繫合作。這是個人品牌網站，不是測驗平台。

## 已知事實與內容邊界

- 原始來源：`ken-components.jsx`、`ai-projects-data.js`、`images/`。

- 17+ 年資與職稱沿用既有網站，沒有重新查核履歷。外部專案、Power BI 報告的線上可用性與內容真實性不屬於本次驗證。
- 人像與專案快照皆為原有資產，未生成或冒用人像。財務作品沒有快照的項目使用文字圖形封面，不以虛構儀表板數據代替。
- 原版首頁完整保存在根目錄 `index-classic.html`；原有 React 元件與 AI 快照頁保持可用。

## 標杆與取捨

已透過瀏覽器實際查看：

- [Brian Lovin](https://brianlovin.com/)：小幅人像、短身分敘述、單欄內容列表；保留「快速知道是誰、能看什麼」的資訊優先順序。Ken 有財務跨域故事與多件作品，增加人物敘事與可篩選作品，不複製其單欄部落格結構。
- [Maggie Appleton](https://maggieappleton.com/)：通欄大字為主角、不同內容類型有明確區別、導覽克制；借用字級差與編輯式閱讀節奏，換成 Ken 的實際人像、職涯與專案內容，不複製數位花園插畫。
- [Animal Island UI](https://github.com/guokaigdg/animal-island-ui) 與[實際展示](https://guokaigdg.github.io/animal-island-ui/)：大面積薄荷色、奶油字、圓角與主按鈕立體按壓。依其[設計 Tokens](https://github.com/guokaigdg/animal-island-ui/blob/main/docs/design-system/design-tokens.md)與[設計規則](https://github.com/guokaigdg/animal-island-ui/blob/main/docs/design-system/design-rules.md)轉譯成原生 HTML/CSS，不安裝套件。深薄荷提高文字對比，保留既有品牌人物；圖形為原創，未使用遊戲角色或商標。

品類常見預設為紫藍發光的開發者首頁，本輪四版皆避開。前三版在首屏骨架、主角、字體與色彩中至少三項不同；島嶼版以有機人物構圖與遊戲式控件增加另一種品牌語氣。

## 操作與關鍵狀態

- 上方四個按鈕即時切換，URL 使用 `?style=editorial|systems|gallery|island`，可直接分享；支援瀏覽器上一頁與下一頁。
- 使用 `localStorage` 記住選擇；瀏覽器拒絕保存時，切換仍可使用並顯示提示。明確 URL 優先於記憶偏好。
- 作品支援精選、財務與營運、AI 與知識、全部篩選；可搜尋、載入更多、從查無結果清除重試。
- Power BI 報告與職涯可展開／收合；報告使用原生 details 檢視分析架構。
- 小螢幕可開啟導覽，Escape 或點擊導覽後收起；鍵盤焦點與跳至內容可用。
- 模擬儲存失敗、減少動態效果、無效 URL 風格、快速切換與重新載入列入檢查。

## 動效與實作取捨

三處基本回應：主按鈕按壓與懸停、風格立即切換與首屏 220ms 淡入、區塊依閱讀順序出場。知識小島主按鈕具有具體的立體按壓深度。

工作方法區使用原生 CSS Scroll-Driven Animations：文字隨閱讀位置轉為主色、水平路徑由短延伸至完整，向上滾動可逆。其餘區塊用 Web Animations API 與 IntersectionObserver 一次性出場，樣式不預設 opacity:0，腳本失敗仍可閱讀。

專案上層 AGENTS.md 要求未同意不新增 dependencies；因此使用瀏覽器原生動畫，沒有另加 GSAP 或其他套件。這是對 oil-ui 建議動效庫的明確取捨。不支援 CSS scroll-timeline 的瀏覽器保留靜態內容，動態效果減少偏好停用位移與過場。

版面涵蓋 390px 手機、768px 平板、1440px 桌面。內容不是四份分叉的履歷；共用語意結構與資料，只變更呈現。

## 獨立評審與修正

一輪獨立看圖評審：顧問誌8/10、系統構築7/10、作品索引8/10、知識小島8/10；整體8/10，無視覺阻斷。評審實際查看桌機與手機首屏、遮字圖及四版全頁圖；未播放影片，不評動效手感。

依評審已修正：系統構築加入HermesAnalytics真實專案畫面；前三件財務/營運作品加入其現有網站真實截圖；移除作品索引重複中英文眉標；小島技能與經歷改為開放列表，降低連續盒狀密度。其他沒有截圖的作品保留文字封面；未為補圖而創造不存在的數據。修正後未做第二輪獨立評分。

最終截圖報告保留的lint：IFRS/XBRL、REST API為技能專有名詞；systems英文大字為指定的排版主視覺；小島章節數字對應實際頁面順序。這些皆有功能/內容理由，其餘可讀性問題已修正。
